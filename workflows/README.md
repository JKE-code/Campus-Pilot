# n8n Workflows

This directory stores exported JSON files for all CampusPilot AI workflows:

1. `01_intake_and_triage.json` — Student submission ingestion, FAQ lookup & AI classification.
2. `02_voice_clarification_callback.json` — Adaptive outbound voice dispatch & callback parser.
3. `03_assignment_and_notifications.json` — Department routing matrix & email dispatchers.
4. `04_incident_clustering.json` — Campus Incident Intelligence cluster detector.
5. `05_sla_escalation_cron.json` — Scheduled SLA monitor & escalation alerts.
6. `06_human_approval_and_closure.json` — Event proposal approvals & student closure confirmation.
